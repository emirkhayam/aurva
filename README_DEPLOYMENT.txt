⚠️  ВАЖНО: ЧТО ИЗМЕНИТЬ В COOLIFY

При настройке переменных окружения ОБЯЗАТЕЛЬНО измените:

1. JWT_SECRET          → сгенерируйте: openssl rand -base64 32
2. AUTH_JWT_SECRET     → сгенерируйте: openssl rand -base64 32
3. ADMIN_PASSWORD      → ваш надежный пароль
4. EMAIL_USER          → ваш email
5. EMAIL_PASSWORD      → App Password от Gmail

Остальные переменные можно оставить как есть.

🚀 БЫСТРЫЙ СТАРТ:

1. Зайдите в Coolify на вашем сервере
2. Создайте новый проект "AURVA Production"
3. Подключите GitHub репозиторий: emirkhayam/aurva
4. Выберите Docker Compose: docker-compose.production.yml
5. Добавьте домены: c.aurva.kg и www.c.aurva.kg
6. Включите SSL (Let's Encrypt)
7. Добавьте переменные окружения (измените секреты!)
8. Нажмите "Deploy"
9. Через 5-10 минут → https://c.aurva.kg/ 🎉
